# Crypta Copy Review

This local static review interface is separate from the macOS app. It does not access vaults, read media titles, or send network requests.

Open `index.html` in a browser. Review state is stored in the current browser's `localStorage`; **Export review results** generates `crypta-copy-review.json` for subsequent human review before applying changes to the app.

Proposed copy from this review interface must not be written into Crypta's product interface without explicit approval.
